A study guide for the IRL Developer role

Learn the job, not the interview.

ASUCD's Innovation & Research Lab is hiring a student developer. It asks for one language, some frontend or backend, and basic Git — so the useful preparation is not interview theatre, it is actually knowing this material. Fifteen sections of JavaScript, the web platform, accessibility, Git, debugging and documentation, with drills and a self-test. The application and interview parts are at the end, and they are short.

None of this expires with the deadline.

The application closes on October 1. The material above does not. A deployed project, an accessibility habit, a Git workflow you do not have to think about, and the ability to explain closures and the event loop out loud are worth considerably more than any single ten-hour-a-week job — and they transfer intact to every application after this one. Study it for the role. Keep it because it is the job.
